# Zángano Pictures 360

Página web desarrollada para **Zángano Pictures**, una empresa orientada a la creación de contenido audiovisual, experiencias virtuales y fotografía en **360º**.

El objetivo del proyecto es ofrecer una plataforma moderna y visual desde la que mostrar los servicios de la empresa, trabajos realizados, clientes, noticias y diferentes proyectos relacionados con el mundo virtual y el contenido inmersivo.

## 🌐 Sobre el proyecto

La web está diseñada para transmitir de forma visual el trabajo realizado por Zángano Pictures, dando especial importancia al contenido multimedia y a las experiencias en 360º.

Cuenta con una interfaz adaptable a diferentes dispositivos y una estructura pensada tanto para los visitantes como para la gestión interna de contenidos.

## ✨ Funcionalidades principales

* Presentación de los servicios de la empresa.
* Galería y contenido visual de proyectos realizados.
* Experiencias y contenido relacionado con fotografía y vídeo 360º.
* Sección de clientes.
* Sistema de reseñas.
* Apartado de noticias y novedades.
* Formulario y sección de contacto.
* Integración con redes sociales.
* Diseño responsive para ordenador, tablet y dispositivos móviles.
* Panel de administración para gestionar diferentes contenidos de la página.

## 🛠️ Tecnologías utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**
* **PHP**
* **MySQL / MariaDB**
* **Apache / XAMPP**

## 🎯 Objetivo

Este proyecto busca crear una presencia digital profesional para Zángano Pictures, permitiendo mostrar sus servicios y proyectos de una manera moderna, atractiva e inmersiva.

Además, el desarrollo incluye herramientas de administración que permiten actualizar el contenido de la web sin necesidad de modificar directamente el código.

## 👨‍💻 Desarrollo

Proyecto desarrollado como página web personalizada, trabajando tanto en el **frontend** como en el **backend**, incluyendo diseño de interfaz, programación, gestión de base de datos y desarrollo del panel de administración.
